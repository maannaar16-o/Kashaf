# نقطة استقبال الإسهام — التنفيذ المرجعي (`DEC-253`)

هذا المجلد **مرجع غير منشور**: كود نقطة الاستقبال جاهزاً للنشر بيد مالك المشروع وحده. حتى نشره، قناة الإسهام في الموقع تعمل بالوضع اليدوي (ملف يُنزَّل أو يُشارَك).

## خطوات التفعيل (مرة واحدة)

1. حساب [Cloudflare Workers](https://workers.cloudflare.com) المجاني → أنشئ Worker جديداً والصق `worker.js`.
2. أنشئ KV namespace باسم `CONTRIB` واربطه بالـWorker (Settings → Bindings).
3. انشر، وخذ الرابط (مثل `https://kashaf-contrib.<حسابك>.workers.dev`).
4. ضع الرابط في `build_site.py` (`CONTRIB_ENDPOINT`) وأعد البناء والنشر — يظهر زر «أرسل الآن مباشرة» تلقائياً.

## عهود الخصوصية الملزمة للتشغيل

- لا تسجيل لعناوين الشبكة ولا للترويسات — الحمولة المتحقَّق منها وحدها تُخزَّن (منفَّذ في الكود: إعادة بناء صريحة للسجل).
- المعرّف عشوائي (`crypto.randomUUID`) — لا اشتقاق من أي شيء يخص المُرسِل.
- الرفض الصارم لأي حمولة خارج مواصفة `RAWAHIL-CONTRIB-v1` (94 بنداً بمداها، لا حقول زائدة).
- تصدير البيانات للتحليل يكون دفعةً مجهّلة كما خُزِّنت — لا إثراء ولا ربط.

أي توسيع للمواصفة أو تغيير في هذه العهود يستلزم قراراً مختوماً جديداً يُنشر قبل تفعيله.
